> - **Optics & Lighting:** Shot on Hasselblad H6D-100c or Sony A7R V with 85mm f/1.4 lens, soft directional morning light, subtle golden rim accents, shallow depth of field, natural tactile textures.
> - **Target Aspect Ratio:** `16:9` (1920×1080) or `1.91:1` (1200×630 OpenGraph).
> - **Recommended Engines:** Google AI Flow / Imagen 3 / Midjourney v6 / Gemini Image FX.

## 4. Image Production & Upload Checklist

1. **Aspect Ratio:** Generate in `16:9` (1920×1080) or `1.91:1` (1200×630).
2. **Format:** Export as `.png` or `.webp`.
3. **Dimensions:** Ensure width is `1200px` and height is `630px` (or compress via Sharp/Squoosh).
4. **Save Folder:** Put new blog images into `prototype/public/blog-images/` named descriptively (e.g., `saas-conversion-engine.webp`).
5. **Update Index:** Run `npm run prebuild` to automatically sync the new images with the blog index and verify zero SEO errors.
